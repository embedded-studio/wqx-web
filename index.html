文曲星 emulator

Choose or drop the image files of one machine.

NAME.nor is needed. Add NAME.rom (NC1020, PC1000 and CC800), or NAME.nand0 and NAME.nand (NC2000, NC2600 and NC3000), as the model has them. The older models PC505, PC506 and PC530 need NAME.rom alone.

The files are read in this browser and never uploaded. The page does not include any firmware.

Image set

NC3000 sound: the co-processor's program is read from the NAND (/sysdir/升级061.bin). A copy of that file, chosen with the images, is used instead. The TC808 has none: choose an NC3000's or TC1000S's copy with its images for speech.

Remembered image sets

    Save states

      A state includes the machine, its NOR and the NAND blocks that differ from the image files. A save state of the terminal port (--save-state FILE, the file without .nor and .nand) loads too; the flash then stays as it is.

      Flash memory

      What the machine writes to its NOR and NAND is kept in this browser for this image set, never in the image files. The downloads are complete image files with the changes.

      PC keys

      Some browsers keep F5, F11 or F12 for themselves; use the Alt keys or the keypad. Emulation pauses while the page is hidden.
